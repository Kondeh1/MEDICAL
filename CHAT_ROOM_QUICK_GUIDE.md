# Chat Room - Quick User Guide

## For Providers

### Sending Messages
1. Type your message in the text box at the bottom
2. Press Enter or click the send button (➤)
3. Message appears instantly for both you and the patient
4. No page reload needed!

### Creating Prescriptions in Chat
1. Click the prescription button (💊) in the chat header
2. Fill in the prescription form:
   - **Medication**: Name of the medicine (e.g., "Amoxicillin")
   - **Dosage**: Amount per dose (e.g., "500mg")
   - **Frequency**: How often (e.g., "3 times daily")
   - **Duration**: How long (e.g., "7 days")
   - **Notes**: Additional instructions (optional)
3. Click "Send Prescription"
4. Prescription appears in the chat immediately
5. Patient can download it as PDF or DOCX

### Video/Audio Calls
- Click the video camera icon (📹) for video call
- Click the phone icon (📞) for audio call

## For Patients

### Viewing Messages
- All messages appear in real-time
- Provider messages on the left
- Your messages on the right

### Receiving Prescriptions
- Prescriptions appear as special cards in the chat
- Shows medication details
- Click "PDF" to download as PDF
- Click "DOCX" to download as Word document

### Downloading Prescriptions
1. Find the prescription message in chat
2. Click either:
   - **PDF** button - Opens/downloads PDF version
   - **DOCX** button - Downloads Word document version
3. Save or print the prescription

## Features

### Real-Time Updates
✓ Messages appear instantly without refreshing
✓ Both parties see updates in real-time
✓ Smooth animations for new messages

### Chat Themes
- Click the colored circles at the bottom to change chat background
- Choose from 6 different color themes

### Online Status
- Green dot = User is online
- Gray dot = User is offline
- Shows last seen time when offline

## Tips

### For Providers
- Create prescriptions directly in chat - no need to leave the conversation
- Use the notes field for special instructions
- Prescriptions are automatically saved to the patient's records

### For Patients
- Download prescriptions immediately after receiving them
- Keep copies for your records
- Ask questions about prescriptions in the chat

## Troubleshooting

### Messages not appearing?
- Check your internet connection
- Refresh the page
- Messages are saved even if they don't appear immediately

### Prescription button not visible?
- Only providers can send prescriptions
- Patients can only receive and download them

### Download not working?
- Try the other format (PDF or DOCX)
- Check your browser's download settings
- Contact support if issue persists

## Keyboard Shortcuts

- **Enter**: Send message
- **Shift + Enter**: New line in message
- **Esc**: Close prescription modal (if open)
